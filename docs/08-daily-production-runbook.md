# 08 — Daily Production Runbook & Call Sheet

*The repeatable operating manual for a single production day. The goal: **ship both segments, every weekday, without drama.** Consistency is the whole game (see the success ladder in [06](./06-roadmap-and-metrics.md)). Print the call sheet at the bottom each morning, or copy it into your calendar tool.*

> **Segments produced each day:** ☀️ **Lunch Break Live** (10 min, live, ~12:00pm) · 🌙 **The Evening Show** (20 min, guest, evening drop). See format in [02](./02-content-programming.md); kit in [07](./07-video-production.md).

---

## The day at a glance

```
 8:30   Production standup (15 min) — lock the day
 9:00   Story selection + Blow's Live prep
10:30   Evening Show guest prep + pre-call
11:30   ⚙️ TECH CHECK (hard stop — 30 min before air)
12:00   ☀️ LUNCH BREAK LIVE — GO LIVE (10 min)
12:15   Live debrief + editor starts pulling clips
 1:00   Lunch / reset
 2:00   🌙 EVENING SHOW record (or pull from bank)
 3:00   Edit: Evening Show polish + clip cutting
 5:00   Schedule clips · draft Daily Read · QC the Evening Show
 6:30   🌙 EVENING SHOW publishes + clips queued
 7:00   Community pass · set tomorrow's call sheet
```

> Times are a template — shift the whole block to fit Blow's schedule. What matters is the **sequence and the hard stops**, not the clock.

---

## Roles for the day

| Who | Owns |
|-----|------|
| **Host (Charles Blow)** | On-camera, editorial calls, the take, the guest |
| **Producer / showrunner** | Run-of-show, the clock, booking, the call sheet, "go/no-go" |
| **Editor** | Clip pipeline + Evening Show polish (the growth engine) |
| **Live producer** *(or producer in P1)* | Stream health, chat, lower-thirds, the countdown |
| **Social/community** *(P1: producer)* | Scheduling, captions, comment replies |

*In Phase 1 one or two people wear all hats. The runbook stays the same — just fewer hands.*

---

## Standup agenda (8:30, 15 min)

1. **Lunch Break Live story** — what's the one story? What's Blow's angle?
2. **Evening Show guest** — confirmed? Tech check time? Topic + 3 anchor questions?
3. **Clip targets** — any must-cut moments to watch for live?
4. **Risks** — connection, guest reliability, breaking-news pivot?
5. **Backup** — is the evergreen fallback episode ready if today breaks?

---

## ☀️ LUNCH BREAK LIVE — run of show (10 min, LIVE)

**T‑30 — Tech check (hard stop):**
- [ ] Stream key live; OBS/Streamyard connected to YouTube (+ simulcast targets)
- [ ] Audio levels checked (mic, no clipping, no hum) — **the #1 thing**
- [ ] Lighting + framing locked; backdrop tidy
- [ ] Lower-third + title card loaded; "Subscribe" bug ready
- [ ] Internet: hardwired ethernet up; **hotspot backup on standby**
- [ ] Chat monitor on second screen; moderator ready
- [ ] Evergreen fallback clip queued in case the stream drops

**On air (10:00):**

| Time | Beat |
|------|------|
| 0:00–0:30 | Animated open + cold welcome ("Here's what I'm watching today…") |
| 0:30–7:00 | **The take** — Blow's read on the day's biggest story (can include "The Receipts" / "The Throughline") |
| 7:00–9:00 | Live chat — react to 1–2 sharp audience questions |
| 9:00–10:00 | **What Now?** action + CTA: "Evening Show tonight with [guest] · subscribe / newsletter" + close card |

**The host's job:** speed and clarity over polish. Live = human. If something breaks, narrate it and keep going.

---

## 🌙 THE EVENING SHOW — run of show (20 min, recorded)

**Pre-call (T‑30 before record):**
- [ ] Guest mic/camera/lighting checked on Riverside (record **separate local tracks**)
- [ ] Backup audio recording running (phone/recorder) as insurance
- [ ] Names/titles confirmed for lower-thirds; pronunciation noted
- [ ] Blow's 3 anchor questions + 1 "What Now?" close ready
- [ ] Guest briefed: format, length, that it's clipped, the vibe (smart, not gotcha)

**Record structure (~20 min):**

| Time | Beat |
|------|------|
| 0:00–0:30 | Open + guest intro (who they are, why now) |
| 0:30–3:00 | **In Their Words** — set the table, the human/origin hook |
| 3:00–15:00 | **The conversation** — the issue driving the news cycle; anchor questions + follow-ups |
| 15:00–18:00 | **Devil's Advocate** — Blow tests the strongest counter-view |
| 18:00–20:00 | **What Now?** — the action; thank-you; subscribe + newsletter CTA |

**Capture for clips:** the editor flags 3–5 standalone moments live (timestamp + one-line hook) so cutting starts immediately.

---

## Post-production handoff (the clip pipeline)

Clips are the highest-leverage output — treat as an SLA ([07](./07-video-production.md)).

- [ ] **≥6 clips/day** total across both segments, vertical, **captioned**, branded template
- [ ] Each clip: 2-second hook · one complete idea · ends on subscribe/clip CTA
- [ ] **Daily Read** note drafted from the Live take (→ Substack/LinkedIn/IG)
- [ ] **Quote of the Day** graphic from the Evening Show
- [ ] Episode published with title, thumbnail, chapters, pinned "What Now?" + newsletter link
- [ ] Clips **scheduled** across platforms per the calendar ([09](./09-editorial-calendar.md))

---

## End-of-day close (7:00)

- [ ] Both segments published ✅ / community thread posted
- [ ] Reply to top comments on YouTube + IG (community is retention)
- [ ] **Set tomorrow's call sheet** (fill the template below)
- [ ] Confirm tomorrow's guest + tech-check time
- [ ] Top up the **bank** — is there ≥1 evergreen Evening Show in reserve?

---

## Contingency playbook

| If… | Then… |
|-----|-------|
| **Stream drops mid-Live** | Cut to evergreen fallback; reconnect via hotspot; resume or post recap |
| **Guest cancels** | Pull a **banked Evening Show**; never go dark. (This is why we keep a reserve.) |
| **Breaking news mid-day** | Lunch Break Live pivots entirely; Evening Show can become a rapid-reaction solo |
| **Audio failure** | Switch to backup recording; worst case, ship audio-only + captions |
| **Editor out** | Auto-tool (Opus/Descript) first-pass clips; host picks moments; reduce to 3 clips |
