# 09 — Editorial Calendar

*One calendar governs everything. A single weekly **theme** flows across both daily segments, every clip, the column, and all four platforms — adapted to each, never copy-pasted (see [03](./03-platform-strategy.md)). This doc gives you (1) the repeatable weekly template, (2) a fully worked sample month, and (3) the planning cadence.*

**Legend:** ☀️ Lunch Break Live · 🌙 Evening Show · 📰 Column · ✉️ Newsletter · ▶️ YouTube · 📸 Instagram · ✍️ Substack · 💼 LinkedIn · ✂️ clip

---

## 1. The repeatable weekly template

Every week has **one theme**. Mon–Thu run the standard two-segment grid; **Friday** swaps in Mailbag + ships the column & newsletter.

### Daily output grid (Mon–Fri)

| | MON | TUE | WED | THU | FRI |
|---|-----|-----|-----|-----|-----|
| **☀️ Lunch Break Live** | live take | live take | live take | live take | live take |
| **🌙 Evening Show** | Guest A | Guest B | Guest C | Guest D | **Mailbag** |
| **▶️ YouTube** | both segments + 2 ✂️Shorts | both + 2 ✂️ | both + 2 ✂️ | both + 2 ✂️ | both + best-of ✂️ |
| **📸 Instagram** | 1 Reel + Stories | 1 Reel + Stories | Carousel + Reel | 1 Reel + Stories | Reel + week recap carousel |
| **✍️ Substack** | Daily Read note | Note | 📰 **Column** *(or Mon)* | Note | ✉️ **Newsletter** |
| **💼 LinkedIn** | text essay | clip + framing | — | text essay | column excerpt |

### Per-platform weekly quota (targets)

| Platform | Cadence | Source |
|----------|---------|--------|
| ▶️ **YouTube** | 10 long-form (2/day) + ~10 Shorts | both segments |
| 📸 **Instagram** | 5 Reels + 2 carousels + daily Stories | clips + quotes |
| ✍️ **Substack** | 1 Column + 1 Newsletter + 2–4 Notes | the writing layer |
| 💼 **LinkedIn** | 3–4 posts | column excerpts + clips |
| ✂️ **Clips** | **≥6/day → ~30/week** | the growth engine ([07](./07-video-production.md)) |

> **Adaptation, not duplication:** the week's theme becomes a YouTube *title*, an IG *hook*, a LinkedIn *thesis*, and a Substack *argument* — phrased for each audience.

## 4. Planning cadence

| When | Ritual | Output |
|------|--------|--------|
| **Monthly** (last Fri) | Theme + guest planning | 4 weekly themes, Big Interview booked, tentpoles slotted |
| **Weekly** (Fri, 45 min) | Lock next week | Themes confirmed, guests confirmed, column angle, clip targets |
| **Daily** (standup) | Execute | The call sheet ([08](./08-daily-production-runbook.md)) |

**Always-on guardrails:**
- **Mix ~70% evergreen / 30% news-pegged** so the library ages well; leave Live fully topical.
- **Keep ≥2 banked Evening Shows** so a cancellation never goes dark.
- **Breaking-news override:** any day's theme yields to a major story — Live pivots first, Evening can go rapid-reaction.
- **Vary the guest archetype** day to day (official → scholar → organizer → author) so the grid never feels samey.

## 5. Suggested tooling

- **Master calendar:** Notion / Airtable database (one row per asset: date, platform, segment, theme, status, owner, link).
- **Scheduling:** Buffer / Later / Metricool for IG + LinkedIn; YouTube + Substack native schedulers.
- **One source of truth:** every clip and post traces back to its segment + theme row, so nothing ships orphaned.

> A ready-to-fill Airtable/Notion schema can be generated next if useful — base fields: `Date · Day · Theme · Segment · Platform · Asset type · Hook/Title · Owner · Status · URL`.
